Once set up, this is your whole day: switch the terminal to an account and
type the `aws` commands you already know.

```text
❯ cloudhop use acme-dev
[ aws acme-dev (us-east-1) ]
❯ aws ecs list-clusters
❯ cloudhop use acme-prod
[ aws acme-prod (us-east-1) PROD ]
❯ aws s3 ls
```

No profile names, no `--profile`, no `aws sso login`. Three commands get you
there.

<Aside>
`acme-dev` and `acme-prod` are example aliases. You choose your own names in
step 2, for example `billing-dev` or `data-prod`.
</Aside>

## What you need

- **Node.js 20** or newer, to install cloudhop.
- **AWS CLI v2**. Don't have it? `cloudhop doctor` offers to install it.
- An **AWS IAM Identity Center** portal (a URL like
  `https://acme.awsapps.com/start`) or a **personal AWS account**.

## Set it up

<Steps>

1. **Install cloudhop**

   ```sh
   npm install --global cloudhop
   ```

   You get two commands: `cloudhop` and its short form `hop`.

2. **Add your accounts: `cloudhop add`**

   ```sh
   cloudhop add
   ```

   <Tabs>
     <TabItem label="Company SSO portal">
       Choose **IAM Identity Center (SSO portal)**, paste your portal's start
       URL (for example `https://acme.awsapps.com/start`) and its region, and
       give it a short name such as `acme`.
     </TabItem>
     <TabItem label="Personal account">
       Choose **Personal account (aws login)** and a default region. See
       [Personal accounts](/cloudhop/guides/personal-accounts/) for what your
       user needs.
     </TabItem>
   </Tabs>

   Your browser opens: sign in as always and approve. cloudhop then lists
   every account and role you can use. Tick the ones you want and give each
   an **alias**, a short name with its own region:

   ```text
   ◇  acme-production / AdministratorAccess
   ◆  Alias (what you will type)   acme-prod
   ◆  Region for acme-prod         us-east-1
   ```

   Have several portals? Run `cloudhop add` once per portal.

3. **Set up your terminal: `cloudhop shell`**

   ```sh
   cloudhop shell
   ```

   It asks, then adds one line to your shell's startup file (`~/.zshrc`,
   `~/.bashrc`, fish's `config.fish` or your PowerShell profile). Open a new
   terminal afterwards. From then on, your terminal can:

   - **switch accounts** with `cloudhop use <alias>`, and you type plain
     `aws` after that;
   - **sign you in by itself**: an expired session opens the browser and
     your `aws` command carries on;
   - **protect production**: on a production alias, `aws` asks before
     anything that may change resources;
   - **follow your projects**: a folder with a `.cloudhoprc` switches to its
     alias when you `cd` into it;
   - **show the alias in your prompt**, Starship included, so you always
     know which account you are in;
   - **complete aliases** with <kbd>Tab</kbd>.

   <Aside title="Why a line in my shell?">
   A program can't change the environment of the terminal that started it;
   only the shell itself can. That's why it needs this one line. Without it, `cloudhop use` opens a new shell
   instead, and `hop <alias> ...` still works.
   </Aside>

</Steps>

<Aside type="tip">
`cloudhop setup` does all three in one guided run (and can teach your AI
assistant to use cloudhop at the end).
</Aside>

## Work with `aws` as usual

```sh
cloudhop use acme-dev          # this terminal is now acme-dev (or just `cloudhop use` to pick)
aws sts get-caller-identity    # who am I? acme-dev
aws ecs list-clusters          # any aws command you know, unchanged
terraform plan                 # Terraform, CDK and SDKs see it too

cloudhop use acme-prod         # switch accounts
aws s3 ls                      # now as acme-prod
cloudhop use --off             # back to no account
```

`cloudhop use` is the switch between accounts: it sets the alias' account,
role and region in **this terminal only**. Other terminals keep theirs, so
you can have `acme-dev` in one tab and `acme-prod` in another.

### When a session expires

Nothing to do. The next `aws` command renews the session silently or opens
your browser to sign in, then runs. Nothing checks your sessions in the
background.

- **Mark production aliases**: `cloudhop prod acme-prod`.
- **Teach your AI assistant**: `cloudhop agent install`.
- Prefer a web page? [`cloudhop ui`](/cloudhop/guides/web-ui/).
